# SenEvent

Plateforme d'evenements culturels de Dakar : une application web (React) et une application mobile (React Native), un backend Supabase.

Projet du cours DAWM, Master 1 RETEL, DMI/FST/UCAD.

## Equipe
Voir le dossier `equipe/`.

## Devise de l'equipe
Devise : Un code, deux ecrans, Dakar dans la poche

## En ligne
- Application web : https://senevent-equipe-1.vercel.app
- Application Android (APK) : https://expo.dev/accounts/mansour-ndiaye/projects/senevent/builds/1
- Version mobile : 1.0.0 (profil EAS "preview")

## Lancer le projet en local
- npm install a la racine
- Web : apps/web, creer .env.local (VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY), npm run dev
- Mobile : apps/mobile, creer .env (EXPO_PUBLIC_...), npx expo start
