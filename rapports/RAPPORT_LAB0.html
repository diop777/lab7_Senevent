1. Introduction & Objectifs du Lab 0

Le Lab 0 pose les fondations collaboratives de tout le semestre DAWM. Développer une application d'envergure comme SenEvent en équipe exige une discipline stricte de gestion de versions afin d'éviter l'écrasement mutuel de fichiers et les versions non synchronisées.

  • Maîtrise des 3 zones locales de Git : Répertoire de travail (Working Tree), Zone de préparation (Staging / Index) et Dépôt local (.git).
  • Authentification moderne : Configuration de clés cryptographiques SSH (ed25519) reconnues par GitHub.
  • Protection de la branche main : Interdiction de committer directement sur main, obligation de passer par une Pull Request avec relecture.
  • Résolution méthodologique de conflit : Simulation volontaire d'une collision sur la devise de l'équipe dans le README.md et arbitrage propre.
