2. Résolution des Deux Défis Majeurs du Monorepo

A. Un seul package-lock.json à la racine

Si Vercel détecte un package-lock.json dans apps/web/, il tente d'installer le projet de manière isolée et échoue sur une erreur 404 en cherchant @senevent/shared sur le registre npm public. Le nettoyage strict garantit la résolution des workspaces à la racine.

B. Correction du piège des routes profondes (anti-404 SPA)

Dans une SPA, le serveur ne possède que index.html. Une actualisation directe (F5) sur /evenement/3 renvoie 404 par défaut. Nous avons créé apps/web/vercel.json avec une règle de réécriture :

{ "rewrites": [ { "source": "/(.*)", "destination": "/index.html" } ] }
