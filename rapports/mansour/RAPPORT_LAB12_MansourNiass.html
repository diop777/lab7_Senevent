1. Objectifs & Démarche du Lab 12

Le Lab 12 concrétise l'indépendance totale de l'application mobile. En s'affranchissant du serveur de développement et d'Expo Go, ce lab génère un package natif APK Android installable sur n'importe quel smartphone via EAS Build.

Caractéristiques du Binaire Produit
• Application : SenEvent Android Production (v1.0.0)
• Identifiant package : sn.ucad.senevent.equipe1
• Profil EAS : preview (distribution interne avec sortie buildType: "apk")
• Compatibilité : Android 7.0+ (ARM64 / x86_64)

2. Persistance de Session (AsyncStorage)

Contrairement au Web où le token d'authentification est conservé dans le localStorage du navigateur, React Native nécessite une couche de stockage asynchrone pour préserver la session utilisateur entre les redémarrages.

  • Extension de @senevent/shared : La fonction initSupabase(url, key, options?) supporte les options de configuration sans impacter le client Web.
  • Intégration Mobile : Injection de AsyncStorage dans apps/mobile/app/_layout.js avec persistSession: true et autoRefreshToken: true.
